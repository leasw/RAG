# 2026-08-18 B 과제 리스크 보고

## 주요 리스크

- 데이터 제공 범위 확정이 지연되면 시범 분석 일정이 밀릴 수 있다.
- 기관별 데이터 포맷이 달라 전처리 시간이 늘어날 수 있다.
- 분석 방법론 검토가 늦어지면 최종 보고서 일정에도 영향이 생긴다.

## 대응 방안

- 데이터 범위 확정 전까지 공통 컬럼 목록을 먼저 정의한다.
- 기관별 데이터 포맷 차이는 샘플 파일 기준으로 사전 점검한다.
