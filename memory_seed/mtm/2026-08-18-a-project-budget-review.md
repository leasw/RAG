# 2026-08-18 A 과제 예산 검토 메모

## 검토 결과

- 외부 자문비는 유사 사업 사례와 단가표 근거를 함께 제시해야 한다.
- 운영비 항목은 기존 단가표 기준을 적용하되, 예외 항목은 별도 설명이 필요하다.
- 회의 운영비는 횟수와 참석자 수 기준 산식이 필요하다.

## 보완 필요

- 외부 자문비 근거 문서 추가
- 운영비 산식 표 추가
- 예산 항목별 출처 표시
