# 예산 산정 기준

## 기본 원칙

- 인건비와 운영비는 기존 단가표를 우선 적용한다.
- 외부 자문비는 유사 사업 사례와 단가표를 함께 비교한다.
- 모든 예산 항목에는 산식, 단가, 수량, 출처를 표시한다.

## 검토 기준

- 출처가 없는 예산 항목은 보완 대상으로 표시한다.
- 회의 운영비는 횟수와 참석자 수 기준 산식을 제시한다.
- 예외 단가는 별도 사유를 기록한다.
