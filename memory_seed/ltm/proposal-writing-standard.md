# 조직 제안서 작성 기준

## 필수 구성

- 추진 배경
- 사업 목표
- 수행 체계
- 세부 일정
- 예산 산정 근거
- 기대효과

## 작성 원칙

- 일정표에는 내부 검토, 보완, 최종 제출 단계를 구분한다.
- 예산 산정에는 단가표나 유사 사업 사례 등 근거를 표시한다.
- 회의에서 변경된 내용은 최신 회의록과 초안 문서에 동시에 반영한다.
