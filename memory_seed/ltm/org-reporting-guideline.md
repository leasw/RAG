# 조직 보고서 작성 및 검토 지침

## 보고서 기본 구조

- 개요
- 결정사항
- 미해결 쟁점
- 다음 action item
- 관련 문서와 출처

## 검토 원칙

- 확정된 정보와 논의 중인 정보를 분리한다.
- 출처가 없는 일정이나 예산 정보는 확정 정보로 표시하지 않는다.
- 장기 보존 대상 문서는 담당자 승인 후 기준 문서로 승격한다.
