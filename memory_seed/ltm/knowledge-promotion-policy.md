# MTM에서 LTM으로 지식 승격 정책

## 승격 기준

- 확정성: 초안이 아니라 합의되었거나 승인된 정보인가
- 재사용성: 다른 팀이나 프로젝트에서도 다시 참조할 가능성이 있는가
- 대표성: 유사 문서 중 기준본으로 삼을 수 있는가
- 최신성: 현재 정책과 계획을 반영하는가
- 권한성: 공유 가능한 범위가 명확한가
- 출처성: 누가, 언제, 어떤 근거로 만든 정보인지 추적 가능한가

## 승인 흐름

- 에이전트가 LTM 후보를 추천한다.
- 프로젝트 담당자가 검토한다.
- 지식 관리자가 태그와 보존 기간을 확인한다.
- 승인된 문서만 LTM 기준 지식으로 저장한다.
